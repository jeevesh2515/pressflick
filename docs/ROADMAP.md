# Roadmap

## Before going public

1. Test by hand in Safari, Firefox and on a phone. Play the exported MP4 in QuickTime, and upload one to TikTok or Reels.
2. Trademark search for Pressflick, then register the domain and GitHub handle.
3. Contact address in `privacy.html`. Social share image and Open Graph tags.
4. `git init`, push to GitHub, deploy to a static host.

## Next

- Re-run the user research in three months: there were no public reviews of the original to read.
- Talk to 10 creators by hand.
- Playwright end-to-end test for the export flow.

## Later, only if asked for

- Bundled open-licence fonts so pages look the same on every OS.
- More layouts: columns, mastheads, torn edges, paper grain.
- Transparent or green-screen output for editors.
- Paste a list of phrases, get a batch.
